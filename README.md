# Tesla Landing Page Clone

A static Tesla Model S landing page clone built with HTML and CSS.

## Features

- Full-screen hero background image (Model S)
- Tesla navigation bar with model links
- CTA buttons: Custom Order & Existing Inventory
- Background music (plays on first user interaction)
- Responsive layout

## Project Structure

```
tesla/
├── index.html      # Main HTML page
├── style.css       # Stylesheet (uses Shadows Into Light font)
├── logo.png        # Tesla logo
├── model s.jpg     # Hero background image
└── music.mp3       # Background audio
```

## How to Run

Open `index.html` directly in any modern browser — no build step required.

## Notes

- Background audio is triggered on the first user click (browsers block autoplay by policy).
- Navigation links use `href="#"` as placeholders — this is a static clone with no routing.
